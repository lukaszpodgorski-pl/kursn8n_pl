### Dlaczego tworzę to miejsce

Brakowało mi jednego, konkretnego miejsca, w którym znajdę dużo informacji o n8n zebranych
razem. Wiedza jest porozrzucana po wielu źródłach, a do tego sporo twórców nagrywa 15- czy
20-minutowe filmy o czymś, co spokojnie da się zapisać w kilku zdaniach. Takie filmy mają
swoją wartość, ale gdy ktoś szuka miejsca, w którym wszystko jest opisane jasno i czytelnie

- właśnie tego mi brakowało. Dlatego powstała ta wiki.

Zdecydowałem się to robić również dlatego, że teraz, w erze sztucznej inteligencji,
tworzenie tego typu projektów mocno przyspieszyło. Mogę podyktować, co chcę pokazać na
stronie, i zrobić rzetelny research - bo nie ukrywam, sam też nie wiem wszystkiego. Nowe
rozwiązania i elementy, które się pojawiają, najpierw muszę sam poznać i sprawdzić, a
dopiero potem opisuję je w kursie.

:::tip[Darmowe na zawsze]
Ta wiki jest i pozostanie **w 100% darmowa**: bez logowania, bez paywalla, bez "premium".
Nie zarabiam na Tobie - rozwijam ją jako własny, otwarty projekt. Dzięki, że tu jesteś!
:::

:::caution[Aktualność materiałów]
n8n zmienia się bardzo szybko, więc czasem jakiś fragment kursu może być już nieaktualny.
Staram się materiały na bieżąco aktualizować, a docelowo chcę uruchomić bota, który będzie
wykrywał zmiany. Mimo to gdzieś może przemknąć coś przeterminowanego - jeśli trafisz na taki
punkt, [daj mi znać](#o-autorze) od razu, a szybko go poprawię.
:::

## Program kursu: od podstaw do zaawansowanego

To mapa całej wiki - wszystkie 9 modułów jest już dostępnych do czytania. Każdy moduł to
osobny rozdział oparty na oficjalnej dokumentacji n8n. Kliknij dowolny, żeby przejść do
pełnej treści; poniżej w każdym module widzisz, co dokładnie obejmuje. Całość to ~3 h
czytania - w swoim tempie, moduł po module.

**Wszystkie moduły są już dostępne.** Kliknij tytuł modułu lub "Czytaj moduł", aby otworzyć
rozdział.

### 0. Fundamenty automatyzacji

Zanim klikniesz pierwszy node - czym jest n8n i kiedy ma sens.

- Czym jest n8n i do czego służy automatyzacja procesów
- n8n vs Make, Zapier, Power Automate - kiedy które wybrać
- Licencja Sustainable Use License - co wolno, a czego nie
- Słownik pojęć: workflow, node, trigger, execution, credentials
- n8n Cloud vs self-hosted - przegląd dostępnych ścieżek

[Czytaj moduł 0: Fundamenty automatyzacji →](/modul-0-fundamenty)

### 1. Instalacja i hosting

Gdzie i jak postawić n8n, żeby działał stabilnie i bezpiecznie.

- Wymagania systemowe: RAM, CPU, dysk - minimum vs produkcja
- n8n Cloud - najszybszy start bez własnego serwera
- Docker i Docker Compose krok po kroku
- Self-hosting na Raspberry Pi i mini PC (N100/N150)
- VPS i PaaS: cyber_Folks, Hostinger, Hetzner, Railway, Mikrus
- [Porównanie hostingów n8n - kompletny poradnik 2026](/porownanie-n8n-hostingow) (czytaj)
- HTTPS, własna domena, reverse proxy i Cloudflare Tunnel
- Klucz `N8N_ENCRYPTION_KEY` i zmienne środowiskowe
- Aktualizacje i bieżące utrzymanie instancji

[Czytaj moduł 1: Instalacja i hosting →](/modul-1-instalacja-hosting)

### 2. Interfejs i pierwszy workflow

Pierwsze kliknięcia: budujesz i uruchamiasz działającą automatyzację.

- Przegląd interfejsu: canvas, panel node'ów, ustawienia
- Twój pierwszy workflow krok po kroku
- Triggery: Manual, Schedule, Webhook
- Uruchamianie i debugowanie: Execute, pinning danych, lista executions
- Organizacja pracy: foldery, tagi, nazewnictwo workflow

[Czytaj moduł 2: Interfejs i pierwszy workflow →](/modul-2-interfejs-pierwszy-workflow)

### 3. Praca z danymi

Serce n8n: jak przepływają, jak je przekształcać i łączyć.

- Jak n8n przechowuje dane: items i struktura JSON
- Wyrażenia (expressions) i składnia `{{ }}`
- Edit Fields / Set - kształtowanie i mapowanie danych
- Logika: IF, Switch, Filter
- Pętle: Loop Over Items, Split in Batches
- Merge i łączenie danych z wielu źródeł
- Pliki binarne: PDF, obrazy, CSV, załączniki

[Czytaj moduł 3: Praca z danymi →](/modul-3-praca-z-danymi)

### 4. Integracje i API

Łączenie n8n ze światem - gotowe node'y i dowolne API.

- Node'y aplikacji: Google, Slack, Notion, Airtable i inne
- Uwierzytelnianie: API key vs OAuth2 w praktyce
- HTTP Request - uniwersalny klucz do każdego API
- Webhooki: odbieranie i wysyłanie zdarzeń
- Paginacja, limity zapytań (rate limit) i ponawianie

[Czytaj moduł 4: Integracje i API →](/modul-4-integracje-api)

### 5. Kod i sub-workflow

Gdy node'y to za mało - odrobina kodu i modularność.

- Code Node: JavaScript i Python
- Kiedy użyć kodu, a kiedy zostać przy node'ach
- Dane statyczne workflow (static data)
- Sub-workflow (Execute Workflow) i budowa modułowa
- Obsługa błędów: Error Trigger, error workflow, Continue On Fail, retry

[Czytaj moduł 5: Kod i sub-workflow →](/modul-5-kod-sub-workflow)

### 6. AI i agenci

n8n jako orkiestrator AI: od czatu po agentów pracujących 24/7.

- AI Agent node i integracja z LangChain w n8n
- Modele: OpenAI, Anthropic oraz lokalne (Ollama)
- RAG: bazy wektorowe i embeddingi
- Budowa chatbota / asystenta na własnych danych
- Agenci pracujący w tle 24/7 - wzorce i pułapki

[Czytaj moduł 6: AI i agenci →](/modul-6-ai-agenci)

### 7. Produkcja: bezpieczeństwo i niezawodność

To, co odróżnia zabawkę od automatyzacji, której można zaufać.

- Zabezpieczenie instancji: logowanie, 2FA, firewall, reverse proxy
- RODO/GDPR w automatyzacjach - gdzie leżą dane i kto za nie odpowiada
- Backupy w modelu 3-2-1 i testowane odtwarzanie
- Monitoring, logi i healthchecks
- Tryb kolejkowy (queue mode), workery i skalowanie
- Środowiska dev/prod i wersjonowanie workflow przez Git

[Czytaj moduł 7: Produkcja: bezpieczeństwo i niezawodność →](/modul-7-produkcja)

### 8. Wzorce i realne wdrożenia

Sprawdzone schematy, biblioteka workflow i nauka na cudzych błędach.

- Biblioteka gotowych workflow - z wyjaśnieniem, nie do ślepego kopiowania
- Wzorce projektowe automatyzacji
- Case studies i przepisy (recipes) z realnych projektów
- Optymalizacja wydajności i kosztów
- Antywzorce - najczęstsze błędy i jak ich unikać

[Czytaj moduł 8: Wzorce i realne wdrożenia →](/modul-8-wzorce-wdrozenia)
